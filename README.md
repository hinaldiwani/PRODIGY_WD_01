# PRODIGY_WD_01 – Interactive Navigation Menu

## 📌 Project Overview

This project is developed as **Task 01** of the Web Development Internship at **Prodigy Infotech**.

The objective of this task is to create an interactive navigation menu using HTML, CSS, and JavaScript. The navigation menu remains fixed at the top of the webpage and changes its appearance when the user scrolls or hovers over menu items.

## 🎯 Features

- **Fixed Navigation Bar:** The navigation menu stays visible at the top of the webpage while scrolling.
- **Scroll Effect:** The background color of the navigation bar changes when the user scrolls down.
- **Hover Effects:** Menu items change their background and font color when hovered over.
- **Active Navigation Link:** The selected menu item gets a different text color when clicked.
- **Smooth Transitions:** CSS transitions provide smooth visual effects.
- **Responsive Design:** The navigation menu adjusts to smaller screen sizes.
- **Smooth Scrolling:** Navigation links smoothly scroll to their respective sections.

## 🛠️ Technologies Used

- **HTML5:** Used to structure the webpage and navigation menu.
- **CSS3:** Used for styling, positioning, hover effects, transitions, and responsive design.
- **JavaScript:** Used to handle scroll events, click events, and dynamically change CSS classes.
